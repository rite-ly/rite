# rite-resolver

Ceremony resolver for the [Rite](https://github.com/rite-ly/rite) DSL: parses YAML, validates it, and produces a resolved intermediate representation with diagnostics.

Use this crate to build tooling around ceremony files (linters, alternative editors, CI validators) that matches Rite's official validation semantics.

See the [main repository](https://github.com/rite-ly/rite) for documentation, examples, and the full ceremony runtime.
