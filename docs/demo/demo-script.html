Ceremony Protocol

Root Signing Key Ceremony

Overview

Generate an offline root signing key on an air-gapped workstation, issue its self-signed certificate, and export the public half for distribution. Two roles perform and witness the ceremony, and each attests to what they saw.

Roles

  • CO Crypto Officer Alice Rivera
  • Wi Witness Bob Tanaka

Preparation Checklist

Prerequisites

  • Air-gapped workstation is powered on with all network interfaces physically disconnected.
  • Both participants have verified each other's identity against photo ID.
