# Security Policy

> **Note:** Rite is currently in beta (0.x). The API and DSL are subject to breaking changes.
> It is not yet recommended for production ceremony use.

## Reporting a Vulnerability

If you discover a security vulnerability in Rite, please report it responsibly.

**Email:** security@ritely.io

Please include:
- A description of the vulnerability
- Steps to reproduce or a proof of concept
- The version of Rite you are using
