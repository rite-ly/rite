# rite-runtime

Execution engine for [Rite](https://github.com/rite-ly/rite) ceremonies: the channel protocol that frontends drive, the executor, the action and backend registries, and the hash-chained transcript sink.

> **Internal crate.** This is an implementation detail of the `rite` CLI. It has no stable API and does not follow semver across releases. To build on Rite, depend on [`rite-sdk`](https://crates.io/crates/rite-sdk), [`rite-model`](https://crates.io/crates/rite-model), or [`rite-resolver`](https://crates.io/crates/rite-resolver) instead.

See the [main repository](https://github.com/rite-ly/rite) for documentation.
