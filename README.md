# Rite

A DSL and runtime for cryptographic key ceremonies.

> **Beta** — Rite is under active development. Expect breaking changes.

## License

Rite is currently licensed under GPLv3. We chose GPL as a familiar copyleft license for an
early-stage project where we want to keep the core open while retaining flexibility to revisit
licensing later. The SDK and model crates are expected to move to a more permissive license
such as MIT or Apache 2.0 in the future.
